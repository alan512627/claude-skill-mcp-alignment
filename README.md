## Setup on a new machine

Claude's auto-memory is stored per machine, so on each new computer put the rule below into `~/.claude/CLAUDE.md` (Windows: `C:\Users\<you>\.claude\CLAUDE.md`). `CLAUDE.md.template` in this repo contains the same text.

```
cat CLAUDE.md.template >> ~/.claude/CLAUDE.md
```
