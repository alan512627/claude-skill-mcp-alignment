**Tool Knowledge**

For file parsing tasks involving Windows log files, UTF-16 encoded files (identified by BOM bytes `ff fe`) required explicit `raw.decode('utf-16')` while others used `windows-1252`; trying multiple encodings in sequence (`['utf-16', 'windows-1252', 'utf-8-sig']`) was the reliable pattern.
