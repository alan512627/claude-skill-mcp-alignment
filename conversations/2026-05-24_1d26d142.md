**Tool Knowledge**

In the sandbox environment, all external network requests are blocked except `api.anthropic.com`. When lightweight-charts is needed without CDN access, the working approach is to `pip install lightweight-charts --break-system-packages` and extract the bundled JS from `/usr/local/lib/python3.12/dist-packages/lightweight_charts/js/lightweight-charts.js` (~161KB), then inline it directly into the HTML output. TradingView widget scripts fail silently in artifact sandboxes due to iframe origin restrictions, not JavaScript errors — the fix is to avoid TradingView widgets entirely in sandbox contexts and use lightweight-charts instead. For Taiwan stocks in TradingView, the correct symbol format is `TWSE:6456`; for US stocks it is `NASDAQ:VUZI`.
